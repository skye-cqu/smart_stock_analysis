Smart Stock Analysis — A股AI集成投资分析系统
=============================================

一句话定义：A股AI集成投资分析系统，覆盖 选股 → 分析 → 决策 → 回测 全链路。
Python + litellm，LLM只做解读，数值计算用确定性代码。

===============================================================================
各模块详解
===============================================================================

1. 数据层 (src/data/)
---------------------

provider.py          — 数据源优先级链: AkShare(主力) -> Tushare(补充)
                       自动降级，内置 SQLite 缓存(WAL模式，5分钟TTL，默认不缓存)
akshare_client.py    — AkShare 客户端
                       stock_zh_a_daily(新浪源) 获取日K
                       stock_info_a_code_name 获取股票名
                       stock_individual_info_em 获取PE/PB(可选)
tushare_client.py    — Tushare 补充客户端
cache.py             — SQLite 键值缓存，避免重复请求，防限流
models.py            — 数据模型:
                       StockDailyData(日K), StockInfo(基本面),
                       ScoreResult(评分), StrategySignal(信号),
                       AnalysisResult(分析结果)

数据获取流程:
  请求 000001 日K -> 先查缓存 -> 命中则返回
                            -> 未命中 -> AkShare(新浪源) -> 成功则写缓存返回
                                                     -> 失败则试 Tushare


2. 策略层 (src/strategy/)
--------------------------

base.py              — BaseStrategy ABC，定义 calculate_indicators() + generate_signal() 接口
registry.py          — StrategyRegistry，自动发现 builtin/ 下所有策略，支持 YAML 参数注入
builtin/ma_cross.py         — 均线金叉: 5日/20日均线交叉，可配置周期
builtin/macd_divergence.py  — MACD背离: DIF > DEA 且 DIF < 0 时买入
builtin/volume_breakout.py  — 放量突破: 成交量 > N日均量2倍 且 突破20日高点
builtin/rsi_oversold.py     — RSI超卖: RSI < 30 超卖买入，RSI > 70 超买卖出

插件架构: 写一个新策略只需:
  1. 在 builtin/ 下创建 .py 文件
  2. 继承 BaseStrategy
  3. 实现 calculate_indicators + generate_signal
  4. 在 configs/strategies.yaml 中配置参数


3. 评分层 (src/scoring/)
-------------------------

五维评分引擎(参考 KHunter):

  维度        权重    实现
  --------    ----    ----
  技术面      30%     MA趋势 + RSI + 20日高低点
  资金流      30%     5日量价关系 + 换手率
  基本面      15%     PE/PB/ROE 估值
  板块强度    15%     板块相对表现(AkShare行业板块数据)
  事件驱动    10%     放量+涨跌停+连板趋势

一票否决机制: 任何维度得分 < -50 -> 总分直接设为 -100


4. LLM层 (src/llm/)
--------------------

client.py    — litellm 统一封装，支持 DeepSeek/Gemini/Ollama/小米MiMo
               120秒超时，response.usage 空值保护
prompts.py   — 中文分析模板，预计算的技术指标 + 评分 -> LLM 输出 JSON 解读
parsers.py   — 防御式解析，支持 markdown 代码块提取，解析失败返回安全默认值

核心设计: LLM不做数学。所有 MA/RSI/PE 等数值由 Python 确定性计算，
         LLM 只接收预计算结果进行解读。


5. 多代理系统 (src/agents/) — Phase 2
---------------------------------------

schemas.py        — Pydantic 模型:
                    AnalystReport, DebateState, PortfolioDecision, QualityGrade
roles.py          — 7个分析师角色:
                    技术/基本面/新闻/政策/游资/解禁/风控
                    每个是 factory function
debate.py         — 多空辩论引擎:
                    多头 vs 空头 2轮交锋 -> 研究经理综合
                    风险三方辩论(激进/保守/中性) -> 风控总监
memory.py         — TradingMemoryLog:
                    SQLite 存储决策，延迟反思(后续获取实际收益对比)
quality_gate.py   — 双层质量门:
                    Layer1 代码检查(长度/缺失)
                    Layer2 LLM 结构化评分
orchestrator.py   — 编排器:
                    7角色并行 -> 质量门 -> 多空辩论 -> 风险辩论 -> 最终决策


6. 通知层 (src/notifications/)
-------------------------------

feishu.py    — 飞书 Webhook 推送，富文本卡片消息
               (股票名/价格/评分/信号/建议)


7. 流水线 (src/pipeline/)
--------------------------

runner.py    — 流水线执行器: run_pipeline(stock, mode)
               模块级单例(避免重复初始化)，支持 quick/full 两种模式
stages.py    — 流水线阶段定义


===============================================================================
使用方式
===============================================================================

  # 快速模式 — 单LLM分析
  python -m src.main --stock 000001

  # 完整模式 — 7角色多空辩论
  python -m src.main --stock 000001 --mode full

quick 模式流程:
  数据获取 -> 4策略筛选 -> 5维评分 -> LLM解读 -> 输出

full 模式流程:
  数据获取 -> 4策略筛选 -> 5维评分 -> LLM解读
      -> 7角色并行分析 -> 质量门 -> 多空辩论(2轮)
      -> 风险三方辩论 -> 最终决策(Buy/Hold/Sell + 仓位) -> 记忆存储


===============================================================================
配置 (.env)
===============================================================================

  变量                    作用
  --------------------    ----------------------------
  DEEPSEEK_API_KEY        LLM API 密钥
  DEEPSEEK_BASE_URL       LLM API 地址(支持自定义网关)
  LLM_MODEL               模型名(如 openai/mimo-v2.5-pro)
  FEISHU_WEBHOOK_URL      飞书推送地址
  SQLITE_DB_PATH          缓存数据库路径
  CACHE_TTL_MINUTES       缓存过期时间(默认5分钟)

===============================================================================
技术栈
===============================================================================

  - Python 3.11+，纯 Python 异步（无 LangChain/LangGraph）
  - AkShare（数据主力）+ Tushare（补充）
  - litellm（LLM 统一调用）
  - SQLite（缓存 + 决策记忆）
  - Pydantic（结构化输出）
  - 飞书 Webhook（通知推送）
